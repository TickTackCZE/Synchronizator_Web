Zásady ochrany osobních údajů

Kalendářová synchronizace je osobní nástroj s jediným uživatelem, svým provozovatelem.

Jaká data nástroj používá

S oprávněním uživatele čte a zapisuje události v jeho Google Kalendáři (rozsah https://www.googleapis.com/auth/calendar). Z událostí používá jen jejich čas; do cílových kalendářů zapisuje čas a neutrální název.

Kde data zůstávají

Zpracování probíhá výhradně na počítači provozovatele. Nástroj nemá server, databázi ani analytiku. Na disku provozovatele uchovává jen přihlašovací token Google a technický stav synchronizace.

Sdílení

Data z Google API nejsou prodávána, sdílena s třetími stranami ani používána k reklamě nebo trénování modelů. Použití dat odpovídá Google API Services User Data Policy včetně požadavků Limited Use.

Odvolání přístupu

Přístup lze kdykoli odebrat na myaccount.google.com/permissions.

Privacy policy (English)

This is a personal, single-user tool. With the user's consent it reads and writes events in their Google Calendar (calendar scope) and uses only event times. All processing happens on the operator's own machine; there is no server, database or analytics. Only the Google OAuth token and technical sync state are stored locally. Google user data is not sold, shared with third parties, or used for advertising or model training, and its use complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
