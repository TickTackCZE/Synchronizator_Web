Domovoy zálohy

Osobní nástroj s jediným uživatelem, svým provozovatelem. Domácí server provozovatele jednou denně ukládá šifrovanou zálohu svých dat do Google Disku téhož uživatele. Nejde o veřejnou službu a nikdo jiný ho nepoužívá.

Zásady ochrany osobních údajů

Nástroj používá rozsah https://www.googleapis.com/auth/drive.file: vidí a mění jen soubory a složky, které sám vytvořil. K ostatnímu obsahu Disku přístup nemá.

Zálohy jsou zašifrované ještě před odesláním, takže jejich obsah nelze na Disku přečíst. Zpracování probíhá výhradně na serveru provozovatele; nástroj nemá vlastní server, databázi ani analytiku. Lokálně uchovává jen přihlašovací token Google.

Data z Google API nejsou prodávána, sdílena s třetími stranami ani používána k reklamě nebo trénování modelů. Použití dat odpovídá Google API Services User Data Policy včetně požadavků Limited Use. Přístup lze kdykoli odebrat na myaccount.google.com/permissions.

Domovoy backups — privacy policy (English)

A personal, single-user tool: the operator's home server stores a daily, encrypted backup of its own data in the same user's Google Drive. It uses the drive.file scope only, so it can see and modify only files and folders it created itself. Backups are encrypted before upload; all processing happens on the operator's own server, with no separate server, database or analytics. Only the Google OAuth token is stored locally. Google user data is not sold, shared with third parties, or used for advertising or model training, and its use complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
